# Tata Data Visualisation: Empowering Business (Forage Virtual Job Simulation)

## Project Overview
This project was completed as part of the Tata Data Visualisation Job Simulation on Forage. The primary objective was to analyze online retail transaction data, uncover seasonal trends, and present actionable business insights to senior executive leadership.

## Key Responsibilities & Deliverables
* Processed, cleaned, and transformed raw transactional datasets utilizing Power Query and data modeling techniques.
* Designed interactive, multi-page Power BI dashboards focusing on critical metrics such as 2011 monthly revenue trends, customer segmentation, and regional performance.
* Uncovered key seasonal fluctuations, identifying a significant sales surge during holiday shopping periods and top-performing international markets outside the UK.
* Prepared structured business insights and professional documentation to assist senior leadership with data-driven strategic decision-making.

## Files Included in Repository
* **`Tata_Forage_Professional_Report.pdf`**: The formal analytical report and dashboard visuals combined into a clean, uniform A4 portfolio.
* **`Online Retail Analytics.pbix`**: The underlying Power BI project file containing the data model, queries, and interactive dashboards.
